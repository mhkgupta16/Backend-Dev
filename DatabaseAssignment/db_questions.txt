1.  Explain the key differences between SQL and NoSQL databases with
    examples.

Answer: - SQL databases are relational (tables with rows and columns),
while NoSQL databases are non-relational (documents, key-value, graph,
etc.). - SQL uses structured schema (fixed), NoSQL uses flexible
schema. - SQL uses SQL language (e.g., MySQL), NoSQL uses different
query styles (e.g., MongoDB). - SQL is good for complex queries and
transactions, NoSQL is good for scalability and large data. Example: SQL
→ MySQL, PostgreSQL NoSQL → MongoDB, Cassandra

2.  What does the CAP theorem state, and why can’t a distributed system
    guarantee all three properties?

Answer: - CAP theorem states that a distributed system can only have 2
out of 3: 1. Consistency (same data everywhere) 2. Availability (system
always responds) 3. Partition Tolerance (works even if network fails) -
In real systems, network failure can happen anytime, so Partition
Tolerance is required. - Because of this, system must choose between
Consistency and Availability.

3.  Describe three scenarios where MongoDB would be preferred over a
    relational database.

Answer: - When data structure is flexible (e.g., changing fields in user
profiles). - When handling large scale data (big data applications). -
When fast development is needed (no need to design strict schema).

4.  Why does MongoDB use BSON internally instead of storing documents as
    JSON?

Answer: - BSON is binary format → faster processing than JSON. -
Supports more data types (Date, Binary, ObjectId). - Efficient storage
and indexing. - Easier for machines to read/write.

5.  Write MongoDB queries to find all students with GPA above 3.5 and
    enrolled in “CS101”.

Answer: db.students.find({ GPA: { $gt: 3.5 }, course: “CS101” });
